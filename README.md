# Разработка компьютерной игры с динамической генерацией диалогов игровых NPC с использованием генеративных нейросетей

## О проекте

Проект представляет собой разработку компьютерной игры, в которой взаимодействие игрока с неигровыми персонажами (NPC) осуществляется посредством динамически генерируемых диалогов с использованием генеративных нейросетей.

В основе игрового сценария лежит небольшая деревня, населенная персонажами с индивидуальными характерами, знаниями, ролями и особенностями поведения. Игрок взаимодействует с NPC посредством диалога на естественном языке, а персонажи формируют ответы с учетом игрового контекста.

## Цель проекта

Разработка компьютерной игры с системой динамической генерации диалогов NPC, обеспечивающей контекстное взаимодействие игрока с игровыми персонажами и возможность влияния диалогов на игровой процесс.

## Основные задачи

- Разработка концепции и структуры компьютерной игры.
- Проектирование игровых персонажей и их индивидуальных особенностей.
- Разработка системы взаимодействия игрока с NPC.
- Интеграция генеративной нейросети для формирования динамических ответов персонажей.
- Разработка механизма обработки результатов диалога и их влияния на игровой процесс.
- Реализация и тестирование разработанной системы.

## Концепция игры

Игровое действие происходит в небольшой деревне, населенной NPC, обладающими собственными характерами, знаниями и интересами.

Игрок может общаться с персонажами, задавая вопросы и формулируя реплики в свободной форме. Генеративная нейросеть используется для формирования ответов с учетом личности персонажа, текущей ситуации и доступной ему информации.

Результаты взаимодействия с NPC могут влиять на состояние игровых событий, доступные действия и развитие игрового процесса. Для обеспечения управляемости игрового сценария результаты диалогов рассматриваются как часть игровой логики, а не только как текстовые ответы.

## Планируемые компоненты

- Игровая сцена и окружение.
- Неигровые персонажи (NPC).
- Система взаимодействия и диалогов.
- Модуль генерации диалогов.
- Механизм обработки результатов взаимодействия.
- Система управления игровыми событиями и состояниями.

## Статус проекта

Проект находится на стадии проектирования и разработки. Репозиторий предназначен для хранения исходного кода, документации, игровых материалов и результатов разработки.
